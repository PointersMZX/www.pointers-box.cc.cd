为了让大家下载更方便，Pointers-BOX 对发布渠道做了如下调整：

- 「下载」菜单新增**云盘**入口：各版本安装包都已上传，点开即下
- 原 **Gitee** 与**蓝奏云**渠道停止使用，已从「下载」菜单移除
- GitHub 渠道保持不变；国内下载推荐使用云盘

后续新版本也会第一时间同步到云盘，请通过官网「下载」菜单获取最新版本。
