# Pointers-BOX Official Website

This repository contains the source code of the Pointers-BOX official website at <https://www.pointers-box.cc.cd>. The site publishes platform announcements, release notes, client download entries, and usage guides.

## Site Contents

- **Home / Feed**: platform announcements and day-to-day updates
- **Blog**: release articles and the version changelog (pinned)
- **Download**: download entries for Windows installers, portable builds and the Android version (GitHub / Gitee / Lanzou Cloud)
- **Projects**: introduction to the Pointers-BOX client
- **About**: platform introduction, usage guide and community links

## Tech Stack

- Astro static site; the build output is plain static files
- Svelte 5 interactive components + Tailwind CSS
- Site search index generated by Pagefind at build time

## Local Development

Requirements: Node.js ≥ 22, pnpm 11

```bash
pnpm install
pnpm dev      # dev preview at http://localhost:4321
pnpm build    # build into dist/
pnpm preview  # preview the build output
```

## Content

- **Posts**: `src/content/posts/*.md`; `pinned: true` pins a post; `pnpm new-post` creates one
- **Feed**: `src/content/dynamic/*.md`; `pnpm new-dynamic` creates one
- **Projects**: `src/content/projects/*.md`
- **Site config**: under `src/config/`, split by page — site info `siteConfig.ts`, navbar `navBarConfig.ts`, sidebar `sidebarConfig.ts`, announcement `announcementConfig.ts`, wallpaper `backgroundWallpaper.ts`, music `musicConfig.ts`
- **Images & static assets**: `public/`

## Deployment

`pnpm build` outputs a plain static `dist/` directory. Push to the repository and the hosting platform builds and deploys automatically.
